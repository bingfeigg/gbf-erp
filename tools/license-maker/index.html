GBF ERP 许可证签发工具

在本地浏览器内使用您的 Ed25519 私钥 PEM 对载荷签名，生成与后端 src/license.ts 一致的 license.json。私钥不会上传任何服务器。推荐使用 Chrome / Edge 119+；若本机 Web Crypto 不支持 Ed25519，将尝试从 esm.sh 加载备用库（需短暂联网）。

密钥从哪来？

在项目根目录执行：bash scripts/gen-license-keys.sh（或 npm run license:keys），会得到 license_private.pem（保密）与 license_public.pem（部署到客户环境的 LICENSE_PUBLIC_KEY_FILE）。

单实例绑定：在 ERP 控制台「工具 → 许可证」页面复制本机部署 ID，在下方「部署 / 实例 ID」填入相同值后再生成；客户把该 JSON 导入后，仅该实例可通过校验（复制整份 data 目录仍会克隆，强防需硬件方案）。
